# Todo Plus for Zed

Todo Plus adds `todo.txt`-style syntax highlighting, a few slash commands, and Todo-specific code actions for Zed.

## What it includes

- One minimal slash command: `/todo-about`
- One inline-friendly todo generator: `/todo-new Buy oat milk`
- Code actions for marking the current todo done or undone
- Code actions for inserting a new todo above or below the current line
- Syntax highlighting for Todo+ style todo files

## Highlighted syntax

- Completed tasks starting with `x`
- Priorities like `(A)`
- Projects like `+Work`
- Contexts like `@home`
- Metadata fields like `due:2026-03-10`
- Dates in `YYYY-MM-DD` format
